# WeatherApp 🌦️📸

WeatherSnap is an Android Weather Reporting Application built using Kotlin and Jetpack Compose.  
The app allows users to search weather information, capture weather-related photos, create reports with notes, compress images, and save reports locally using Room Database.

---

# Features 🚀

- Search city weather
- Real-time weather information
- Weather report creation
- CameraX image capture
- Image compression
- Save reports locally using Room Database
- MVVM Clean Architecture
- Hilt Dependency Injection
- Jetpack Compose UI
- Navigation Component
- Retrofit API Integration
